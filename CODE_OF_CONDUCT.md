# Code of Conduct

## 1. Purpose

The **TMLS Code Hub** is a community-driven repository where members share AI and GenAI best practices, code examples, and workflows.
Our goal is to maintain a **welcoming, respectful, and collaborative environment** for everyone—regardless of background, experience level, or affiliation.

This Code of Conduct outlines our expectations for behavior as well as how we handle unacceptable conduct.

---

## 2. Our Standards

We are committed to fostering an environment where all participants can contribute and learn. Examples of positive behavior include:

* Being respectful, considerate, and constructive in all interactions
* Providing and accepting feedback gracefully
* Acknowledging and valuing different viewpoints and experiences
* Sharing resources and crediting original authors
* Focusing on what is best for the community

Examples of unacceptable behavior include:

* Harassment, intimidation, or discriminatory remarks
* Personal attacks, insults, or trolling
* Publishing others’ private information without permission
* Excessive or aggressive self-promotion
* Submitting plagiarized or intentionally harmful code

---

## 3. Scope

This Code of Conduct applies to:

* All repository spaces (issues, pull requests, discussions, code reviews)
* Official TMLS-related communication channels (Slack, email, events)
* Any public spaces where you represent the TMLS community

---

## 4. Responsibilities

**Contributors** are expected to:

* Follow this Code of Conduct
* Respect maintainers’ and reviewers’ decisions
* Address requested changes in pull requests promptly and constructively

**TMLS Committee Members & Maintainers** are expected to:

* Review contributions fairly and consistently
* Enforce this Code of Conduct in good faith
* Take action on violations (warnings, PR closure, or ban from participation)

---
